## Commit 规范

每次 commit 要写清楚：**哪道题 + 用了什么方法**，禁止使用 `update`、`fix`、`修改` 这类没有信息量的 commit message。

示例：

```
3. Longest Substring Without Repeating Characters - 滑动窗口 + 哈希表
704. Binary Search - 标准二分模板
```
